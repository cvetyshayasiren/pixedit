# PIXEL LAB

Браузерный пиксель-арт редактор. Рисуйте спрайты с нуля или превращайте фотографии в пиксель-арт — без сервера, без сборки, без аккаунта.

Откройте `index.html` в браузере или поднимите любой статический сервер.

```bash
python3 -m http.server 8080
```

## Возможности

**Рисование**
- Холст от 1×1 до 512×512, пресеты 16 / 32 / 64 / 128
- Кисть, ластик, пипетка, заливка
- Палитра в духе PICO-8, недавние цвета, произвольный HEX
- Отмена / возврат, демо-спрайт «инвейдер»
- PNG в исходном разрешении, с прозрачностью, без масштабирования

**Из фото**
- PNG, JPG, WebP, GIF — drag-and-drop, выбор файла или `Ctrl+V`
- Алгоритмы: Nearest Neighbor, Average, Median, Dominant, квантизация (median cut)
- Bayer-дизеринг, кадрирование мышью, демо-закат без файла
- Результат можно сразу открыть в режиме рисования

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1` / `2` | Рисование / Из фото |
| `B` `E` `I` `G` | Кисть / Ластик / Пипетка / Заливка |
| `[` `]` | Размер кисти |
| `Alt`+клик | Пипетка из любого инструмента |
| ПКМ | Быстрый ластик поверх кисти |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / вернуть |
| `Delete` | Очистить холст |
| `Ctrl+V` | Вставить изображение из буфера |

Буквенные клавиши работают в любой раскладке, включая русскую.

## Структура

```
.
├── index.html          разметка и SVG-спрайт иконок
├── css/
│   ├── tokens.css      цвета, клип-патч, высота навигации
│   ├── base.css        сброс, фон, аврора, зерно, сканлайны
│   ├── layout.css      навигация, сетка панелей, футер
│   ├── controls.css    кнопки, поля, инструменты, палитра
│   ├── stage.css       холст, зум, сетка, статус
│   ├── overlays.css    тосты и модальные окна
│   └── responsive.css  брейкпоинты и reduced-motion
└── js/
    ├── utils.js        DOM-хелперы, цвета, localStorage, PNG
    ├── sound.js        8-битные блипы через Web Audio
    ├── ui.js           тосты, диалоги, справка по клавишам
    ├── stage.js        зум, сетка, оверлей, координаты пикселя
    ├── draw.js         режим рисования
    ├── convert.js      алгоритмы конвертации и демо-закат
    ├── photo.js        режим «из фото»
    └── app.js          вкладки, хоткеи, старт
```

Скрипты подключаются обычными тегами в порядке зависимостей — бандлер не нужен.

## Лимиты

- Холст: 1–512 px по стороне
- Фото: до 4096 px по стороне, до 20 МБ
- История рисования ограничена по объёму памяти (примерно 8–80 снимков)

Цвет кисти и состояние звука сохраняются в `localStorage`.
